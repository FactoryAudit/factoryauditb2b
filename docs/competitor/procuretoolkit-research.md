# Procurement Toolkit 深度竞品研究

日期：2026-08-29
研究方式：抓取 procuretoolkit.com 全站 10+ 页面（首页、4 工具页、模板页、2 篇文章、角色页、工具索引页）+ 外部检索
研究对象：https://procuretoolkit.com/

---

## 〇、一句话结论

Procurement Toolkit 是一个**极简的免费采购工具站**：4 个浏览器工具 + 20 个可下载模板 + 15 篇文章。它的全部竞争力来自三个词：**Free、No signup、Browser-based**。它刻意不做平台、不做注册墙、不做付费墙，用"零摩擦"换取 SEO 流量和工具使用量。

对 FactoryAuditB2B 的核心启示：**工具免费 + 本地计算 + 无注册，是这类站点获取流量的最优解；但它的漏斗在"用完就走"处断掉了，没有把流量沉淀成线索。这正是我们的机会。**

## 4.4 不应该借鉴的（Don't Build）

| 项 | 原因 |
|---|---|
| **模板下载做成产品主体** | 它的模板是主流量入口但零变现；我们已有 7 个真工具，模板只做引流补充，不替代工具 |
| **"数据不出浏览器"作为唯一卖点** | 它因此放弃所有线索收集。我们需要 email 换报告，卖点是"免费 + 有价值"，不是"我们看不到你" |
| **纯本地 JS 无后端架构** | 我们已有 Prisma + Lead + 服务闭环，不应该为"本地计算"推倒架构 |
| **20 个同质模板堆量** | 我们内容策略是 30 篇精做，不做 20 个近似模板稀释质量 |
| **P×I 单维风险模型** | 我们已有六维加权引擎，P×I 只保留为其中一个方法论参考，不替换 |
| **全站单一英文** | 6 语言是我们的差异化，不回归单语言 |
| **工具用完即走** | 我们要补上它断掉的最后一环：结果 → 报告 → 线索 → 服务报价 |
