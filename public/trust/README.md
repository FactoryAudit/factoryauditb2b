# 营业执照 / 公开证件图放置目录

把**已加水印**的营业执照图片放这里，例如 `business-license.jpg`。

然后在 `.env` 里配置：

```
TRUST_LICENSE_IMAGE="/trust/business-license.jpg"
```

## 两条硬规则

1. **先加水印再上传。** 页面会再叠一层斜向水印，但原图本身也应该带水印，
   因为图片 URL 可被直接访问。
2. **敏感字段先遮挡再拍照/截图。** 法定代表人姓名、完整注册地址、完整统一社会
   信用代码不要在图上完整可见。页面展示的这三项会再做一次部分遮挡。

## 不要在图上出现的内容

- 完整的统一社会信用代码
- 完整的注册地址
- 法定代表人完整姓名

## 建议文件名

- `business-license.jpg` — 营业执照
- 需要时再放其他证件
