## 2. 发现的旧商业规则（需处理项）

### F1（P1，必须修复）— `country.metaDesc` 仍含 "certified/accredited suppliers"

9 语字典的 `countryPage.metaDesc` 都把本地供应商目录描述成「certified/accredited suppliers」，与 V2.2 §54 / PHASE 05 信任规则冲突（平台只做 verification，不 issue certificate，不应称 "certified"）。

| 文件:行 | 当前文案（节选） | 应改为 |
|--------|----------------|--------|
| `en.json:1985` | "...Audits, inspections and **certified suppliers** for buyers sourcing from..." | "...and **verified suppliers** for buyers..." |
| `zh.json:1808` | "...提供审核、验货与**认证供应商**。" | "...与**已验证供应商**。" |
| `zh-TW.json:1332` | "...提供審覈、驗貨與**認證供應商**。" | "...與**已驗證供應商**。" |
| `de.json:1332` | "...Audits, Inspektionen und **zertifizierte Lieferanten**..." | "...und **verifizierte Lieferanten**..." |
| `fr.json:1332` | "...Audits, inspections et **fournisseurs certifiés**..." | "...et **fournisseurs vérifiés**..." |
| `es.json:1332` | "...Auditorías, inspecciones y **proveedores certificados**..." | "...y **proveedores verificados**..." |
| `pt.json:1332` | "...Auditorias, inspeções e **fornecedores certificados**..." | "...e **fornecedores verificados**..." |
| `ja.json:1332` | "...監査、検品、**認定サプライヤー**を提供します。" | "...検品、**検証済みサプライヤー**を提供します。" |
| `ar.json:1332` | "...وموردون **معتمدون** للمشترين..." | "...وموردون **مصدقون** للمشترين..." |

> 注：上一轮 V2.2 只修了 `lib/seo.ts:28` 的国家页 description 模板，漏掉了字典里的 `countryPage.metaDesc` 同义字符串。两处语义一致，须同步。
> 影响线上：是（国家页 `<meta name="description">` 对 Google 可见，且会被 llms.txt 之外的页面直接渲染）。
> 修复方式：9 处字典字符串精确替换，不动结构、不动其他键；修复后跑 JSON 校验 + tsc。

### F2（非问题，已核实）— `de.json:2078` 命中 forbidden-pattern 为误报

首轮 forbidden-pattern Grep 命中 `de.json:2078`，但精查确认：
- `de.json` 全仓无 `zehn` / `10-Dim` / `10 dimension` 字面；
- `de.json` 所有 `dimension` 出现均为 `acht`（8）；
- 该长行是 risk framework 描述，其中 "10"（某维度权重 10%）与 "Dimension" 仅因换行/空格相邻被正则 `10\s*dimension` 误抓；
- V2.2 回归脚本 `[3]` 对 `de` 判定 PASS（无 10/six dimension 文案）。

**结论：非违规，不修复。**
