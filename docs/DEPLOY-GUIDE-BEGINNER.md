## 第 1 步：注册 Supabase（免费）

1. 打开 👉 https://supabase.com
2. 点右上角 **"Start your project"** 或 **"Sign Up"**
3. 用 **GitHub 登录最快**（没有 GitHub 就用邮箱注册，免费）

## 第 2 步：新建项目（免费）

1. 登录后点 **"New project"**（新建项目）
2. 填写：
   - **Organization**：用默认的就行
   - **Name**：随便起，比如 `factoryauditb2b`
   - **Database Password**：**设一个你能记住的密码**（先存到手机记事本！）
   - **Region（地区）**：**一定要选 `Singapore`（新加坡）** ← 这很重要，离网站用户近、速度快
3. 点 **"Create new project"**
4. 等 **1～2 分钟**，页面从 "Provisioning…" 变成绿色对勾就好了

## 第 3 步：建表（复制粘贴，不用懂 SQL）

> 想让我代做这步？跳到本文底部"让我替你做"那节。

1. 左侧菜单点 **SQL Editor**
2. 点 **"New query"**（新建查询）
3. 打开你电脑里的这个文件，把里面**全部内容**复制出来：
   ```
   supabase/migrations/001_init.sql
   ```
   （在项目文件夹里找 `supabase` → `migrations` → `001_init.sql`，双击打开，按 `Ctrl+A` 全选 → `Ctrl+C` 复制）
4. 粘贴到 Supabase 的 SQL Editor 空白处（`Ctrl+V`）
5. 点右上角 **"Run"**（或按 `Ctrl+Enter`）
6. 看到 **"Success"** 或绿色提示就成功了（它会建 10 张表）

> 找不到这个文件？直接在聊天里跟我说"把 SQL 发我"，我把全文贴给你。

## 第 4 步：关掉"邮箱验证"（非常重要，否则用户注册不了）

1. 左侧菜单 **Authentication** → **Providers**
2. 找到 **Email**，点开它
3. 把 **"Confirm email"** 这个开关**关掉**（拨到灰色）
4. 点 **Save**（保存）

> 为什么必须关：开着的话，用户注册后要点验证邮件才能登录；而邮件域名还没验证，邮件发不出去，注册就卡死了。

## 第 5 步：复制 3 个密码发给我

1. 左侧菜单 **Project Settings** → **API**
2. 这一页你能看到三样东西，逐一复制：
   - **Project URL** → 长得像 `https://abcdefg.supabase.co` → 复制
   - **anon public** 下面的 **key**（很长一串 `eyJ...`）→ 复制
   - 同一页再往下，**service_role** 下面的 **key**（也是 `eyJ...`）→ 复制
3. 把这 3 样**粘贴到聊天框发给我**就行

就这 3 样：
```
Project URL        = https://xxxx.supabase.co
anon key           = eyJxxxxxxxxxxxxxxxxxxxx
service_role key   = eyJyyyyyyyyyyyyyyyyyyyy
```

> 其余配置（`SUPPLIER_DATA_SOURCE` 等）我帮你设好，不用你管。
